# 手写笔记

一款运行在安卓平板上的**纯手写笔记应用**：完全离线、无需联网、无广告、无多余功能。提供**两种形态**：

| 形态 | 文件 | 用途 |
| --- | --- | --- |
| 网页版（HTML） | `手写笔记2.0.html` | 在浏览器里打开即用，适合快速试用/调试 |
| 安装版（APK） | `手写笔记2.0.apk` | 安装到平板，桌面图标启动、全屏沉浸，推荐日常使用 |

- 打包工程：`android/` 文件夹（Android Studio 工程 + `rebuild.bat` 一键重新打包）
- 预览图：`预览/` 文件夹（界面预览、跨页书写预览、删除高亮预览、PDF 导出预览、示例导出.pdf）

---

## 一、功能特性

| 功能 | 说明 |
| --- | --- |
| 固定 A4 画布 | 底层始终为标准 A4 尺寸（595.28 × 841.89 pt），缩放/平移只改变显示，不改笔迹坐标 |
| 手写 | 黑色圆润笔迹，平滑渲染；最后落下的手指为书写手指 |
| 橡皮 | 局部擦除笔迹，支持跨页擦除 |
| 清屏 | 一键清空当前编辑页 |
| 放大 / 缩小 | 整体等比例缩放，不改变 A4 基准 |
| 新建下一页 | 在文档末尾追加一张空白 A4 纸，**不切换页面、不滚动视图**，可手动下滑到达 |
| 删除页面 | 按一次进入选择（页面高亮），点某页选中（高亮加深），**再点同一页删除**；点空白取消 |
| 删除所有页面 | 按第一次全部高亮，**再按一次全部删除**（保留一张空白页） |
| 保存 | 导出全部页面为标准 A4 多页 PDF，按新建顺序分页 |
| 多页连续排版 | 页面自上而下连续衔接（上一页页尾贴下一页页头），可任意页书写 |
| 跨页书写 | 一笔从一页画到下一页时，在衔接处自动拆分到两页，接缝完全无缝 |
| 本地保存 | 笔记自动保存在本地（网页版存浏览器、APK 存应用数据），关掉再打开内容还在 |

## 二、触摸交互规则

- **单指**：平移画布（带阻尼，页面跟随约 70%，防乱跑）；从右 1/4 区域起手同样可平移
- **多指**：进入书写模式，**最右侧手掌区（右 1/4）之外的触点中，最后落下的手指负责书写**
- **手掌防误触**：右 1/4 区域为手掌区——多指场景下从该区域起手的触点自动视为手掌、完全忽略；手掌在屏时单指也可书写；手掌抬起不中断笔迹
- **工具栏**：书写过程中任何手指都可直接滑到左侧按钮切换工具（抬起即生效）

## 三、使用说明

### APK 版（推荐日常使用）

1. 把 `手写笔记2.0.apk` 传到平板（微信文件传输助手 / 数据线均可）
2. 点开 APK → 允许"安装未知来源应用" → 安装
3. 桌面出现"手写笔记"图标，点开即用（全屏沉浸、无地址栏、屏幕常亮）
4. 点"保存"导出 PDF：输入文件名 → 点导出 → **弹出系统"另存为"窗口，可自由选择保存位置**

### 网页版（HTML）

1. 把 `手写笔记2.0.html` 传到平板
2. 文件管理器点开 → "用 Edge 打开"
3. 建议在 Edge 菜单里点"添加到主屏幕"，之后从桌面图标打开即全屏、无地址栏
4. 点"保存"导出 PDF：可自定义文件名（默认"手写笔记"，记住上次名字）；电脑浏览器上还可"选择位置"并记住上次文件夹

## 四、如何更新网页 / 重新打包 APK

**只改一个文件：** `手写笔记2.0.html`（网页版和 APK 版的网页本体都来自它）

1. 用浏览器打开 `手写笔记2.0.html` 测试、修改，直到满意
2. **双击** `android\rebuild.bat`——它会自动把新版 HTML 同步进 APK 并重新打包
3. 新 APK 生成在：`android\app\build\outputs\apk\debug\app-debug.apk`
4. 传到平板**覆盖安装**即可（同签名覆盖安装，笔记数据不受影响）

## 五、技术说明

- 纯前端单文件：HTML + CSS + JavaScript，零第三方依赖，离线可用
- Canvas 2D 渲染；`Pointer Events` 实现单指/多指精确区分与手掌防误触
- 多页采用"连续纸张流"排版，历史页为只读快照、当前编辑页全分辨率渲染
- PDF 为程序内置生成（矢量曲线笔迹、精确 A4 尺寸），不依赖外部库
- APK 为 WebView 外壳：全屏沉浸、本地保存（DOM Storage）、原生桥接"另存为"选择保存路径

## 六、可调参数（在 HTML 文件开头的常量区）

| 常量 | 默认 | 含义 |
| --- | --- | --- |
| `PALM_ZONE` | 0.25 | 右侧手掌区宽度（屏幕比例），左撇子可改为左侧逻辑 |
| `PAN_DAMPING` | 0.7 | 单指平移阻尼（页面跟随手指的比例） |
| `PAN_SMOOTH` | 0.35 | 平移平滑系数 |
| `PEN_W` | 2.5 | 笔迹宽度（pt） |
| `ERASER_R` | 15 | 橡皮半径（屏幕像素） |
| `MAX_HIST` | 10 | 最多保留的历史页可见快照数（不影响 PDF 导出） |
